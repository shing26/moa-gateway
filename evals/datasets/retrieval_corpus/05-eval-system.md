# 自建评测体系

每次改动可以跑全部维度并输出 JSON 报告。报告里每个维度都写明它到底测的是
什么，以及数字的限定词，就是为了不让全绿被误读。

## 评测维度

评测维度包括：意图路由准确率、意图一致性、守卫对抗、工具选择、端到端、
人工决策回流。每个维度有独立的数据集与跑法，离线模式零网络零 token，跑真实
的业务链路，用纯正则路由与 mock agent。

## 维度的诚实标注

工具选择维度测的是 mock 规则表，不是真实 Agent 的工具选择。意图一致性维度
测模型兜底路径，没有期望值，因此设计者无法自证。这些限定词被直接打在报告
里，而不是藏进脚注。

## CI 与门禁

CI 跑离线模式，不引入网络依赖。门禁阈值先测后定，不在拿到数字前写死目标值。
工具选择是离线确定性用例，任何一次不匹配都说明规则或注册表发生了漂移，
是 Agent 级指标里唯一能进 CI 硬门禁的一项。

## 人工决策回流

人工决策回流把刹车变成标注管道：审批卡片点击后，决策进入数据集，用来计算
人工介入率与放行率。这是本项目独有的数据资产，因为它把人的判断变成了
可统计的信号。

## 报告口径

报告里每个数字都带限定词。端到端的 intent_match 是与数据集标签的偏离率，不是
路由准确率；标签里部分用例的期望值其实是默认桶，与路由 LLM 的判定天然不一致。
离线不判分时如实记 judge_skipped，而不是记 0 分，因为 0 分是"答案差"，没读数
不该长得像 0 分。报告与命令行摘要会把这类限定词直接打出来。
